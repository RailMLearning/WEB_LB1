# Лабораторная №2

## Локальный запуск

В первом терминале из корня проекта:

```sh
python -m pip install -r requirements.txt
python -m uvicorn server.routers.serve:app --host 127.0.0.1 --port 8000
```

Во втором терминале:

```sh
node server.cjs
```

Страница: http://127.0.0.1:8080/. API: http://127.0.0.1:8000/api/requests.

Node отдаёт HTML, JS и CSS, а обращения `/api/` пересылает FastAPI. В браузере используются относительные URL, поэтому запросы остаются на одном origin. FastAPI не отдаёт главную страницу: 404 по адресу http://127.0.0.1:8000/ в текущей структуре ожидаем.

## Docker

```sh
docker compose up --build -d
docker compose down
```

Перед запуском остановите локальные серверы на портах 8000 и 8080. Compose запускает два сервиса: `web` — FastAPI, `frontend` — Node. Фронтенд обращается к backend по имени `web` внутри сети Compose.

В контейнере JSON хранится в `/data/db.json` на именованном томе `students`. Новый том начинается пустым; локальные записи автоматически не переносятся. `docker compose down` сохраняет том, а `docker compose down -v` удаляет его вместе с данными. 05.10.2026 сборка и запуск обоих контейнеров проверены. Создание, QUERY и удаление прошли через Node-прокси; сохранение записи проверено после пересоздания backend.

## API и данные

Данные студентов хранятся списком в `server/db.json`. Другой путь задаётся через переменную окружения `DB_PATH`. Прикладной код использует словари и функции, без собственных Pydantic-моделей.

Маршруты — `server/router/api.py`, проверки студента — `server/validator.py`, проверки фильтров — `server/filter_validator.py`, бизнес-операции и фильтрация — `server/student_manager.py`, чтение и запись JSON — `server/store.py`.

| Запрос | Назначение |
| --- | --- |
| GET `/api/requests` | Список и фильтры в URL |
| GET `/api/requests/{isu}` | Один студент |
| POST `/api/requests` | Создание из JSON |
| PATCH `/api/requests/{isu}` | Изменение переданных полей |
| DELETE `/api/requests/{isu}` | Удаление, ответ 204 без тела |
| QUERY `/api/requests` | Фильтры JSON-объектом в теле |

Фильтры: `isu`, `fio`, `group` (или `grid`), `dormitory` (или `dnum`), `rnum`, `expdate`, `foreigner`, `notes`. ФИО и заметки ищутся по подстроке без учёта регистра, остальные поля сравниваются точно. Условия соединяются через «И».

Пример: `/api/requests?group=M3301&dormitory=8`.

При более чем трёх непустых фильтрах JS использует QUERY, иначе GET. Число три — выбранный порог, в ТЗ конкретного числа нет. QUERY скрыт из Swagger, но работает через форму или HTTP-клиент.

Ошибки: `{"detail":[{"field":"isu","message":"Сообщение"}]}`. Для общей ошибки поле равно `null`. При недоступности backend Node возвращает 502 в том же формате.

JSON-хранилище рассчитано на один процесс Uvicorn. Блокировка синхронизирует потоки одного процесса, а запись через временный файл защищает от частичного перезаписывания JSON. Cookies для данных студентов не используются.
