# Запуск лабораторной через Docker

Из корня проекта, где находится Dockerfile:

```sh
docker build -t web-lb1 .
docker run --rm --name web-lb1 -p 127.0.0.1:8081:8080 web-lb1
```

Откройте [лабораторную](http://127.0.0.1:8081). Для остановки нажмите Ctrl+C в терминале контейнера. Порт 8081 выбран, чтобы не конфликтовать с обычным локальным запуском на 8080.

Dockerfile использует [официальный образ Node.js](https://hub.docker.com/_/node). В контейнер копируются сервер и файлы сайта. Зависимостей npm нет, установка не требуется. Сервер раздаёт статические файлы; логика студентов выполняется в браузере. Процесс контейнера работает от пользователя node.

Внутри контейнера сервер слушает 0.0.0.0:8080, чтобы работала публикация порта Docker. На компьютере порт публикуется только на 127.0.0.1. EXPOSE сам по себе не публикует порт: это делает параметр -p.

Данные студентов остаются в cookies браузера, а не в контейнере. Пересоздание контейнера само по себе их не удаляет. Cookies не разделяются по порту: запуск на 127.0.0.1:8080 и 127.0.0.1:8081 может использовать одни записи. Используйте отдельный профиль браузера, если нужны независимые тестовые данные.

Обычный запуск без Docker: npm start, затем http://127.0.0.1:8080. Проверки: npm test.

В текущей среде команда docker не обнаружена. Dockerfile подготовлен, но сборка и запуск контейнера здесь не проверялись.
